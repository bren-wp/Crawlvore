# Crawlvora website

Deploy this directory to a PHP 8.2+ shared hosting document root (Apache recommended; mbstring recommended). No SQL server, cron, OAuth credentials or external API requests are required at runtime. The catalog reads JSON shards under storage/data on demand. The checked-in manifest is intentionally empty. No live data is included.

Build a new reviewed snapshot outside the public document root using `python tools/build_web_catalog.py approved.jsonl NEW_DATA_DIRECTORY --country HR --publication-reviewed`. Each input line must be an organization record with country (HR/GB), kind (company/entrepreneur/institution/nonprofit/unknown), name, as_of (ISO date), publication_reviewed=true, and optionally registration_number, tax_number and city. The operator must verify the legal basis, source scope, attribution, accuracy and publication approval; the boolean is a workflow gate, not a legal determination. No directors, natural-person identification numbers, private addresses, contacts or credentials are exported. Do not include individual tax identifiers in any field. Keep source data and snapshots outside the public root until reviewed.

Deploy the generated manifest and shards as a single consistent directory; retain storage/.htaccess. On Nginx deny /storage/ explicitly. For high-volume deployments, benchmark the bounded-memory sequential shard search; indexed search and cache improvements are future work. The initial web implementation is English, not a full multilingual production release. Public privacy operator details, source-specific permissions, integration and deployment remain prerequisites.

Sources under sources.json distinguish bulk/API access from lookup-only. The availability of official public data does not imply that every field may be redistributed. For Croatian additional categories consult https://data.gov.hr/ckan/hr/dataset/registar-udruga and https://mfin.gov.hr/istaknute-teme/neprofitne-organizacije/registar-neprofitnih-organizacija/118 and https://mfin.gov.hr/istaknute-teme/drzavna-riznica/racunovodstvo/registar/178. UK officers and other representative data require a separate verified source, lawful publication scope and role-level records. No inferred links or imported director database yet.

Country-specific catalog directories are mandatory: storage/data/HR and storage/data/GB. Each directory has its own manifest and shards. The website defaults to Croatia and never searches mixed countries. The desktop GB importer builds an independent SQLite snapshot; no existing Croatian workspace is modified. Inactive country import tooling is retained outside the public catalog.
