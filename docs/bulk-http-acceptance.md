# Large import acceptance

Run `python tools/bulk_http_acceptance.py` in a fresh checkout with runtime requirements installed. The opt-in test creates an exact 2 GiB valid JSON array, imports 20,000 synthetic records over the authenticated local HTTP interface, verifies the filtered JSON export, checks SQLite integrity and foreign keys, closes the worker and removes its isolated temporary workspace. Smaller tests can specify `--bytes 1048576 --records 1000`. No live workspace or credentials are used. Free-space preflight reserves at least three times the input size plus 512 MiB. The benchmark includes synthetic padding which is parsed but not retained; it does not establish performance for 2 GiB of indexed business fields. Native WebView2/WebKit file selection, uploads, downloads, peak process memory and production package acceptance are separate requirements.
